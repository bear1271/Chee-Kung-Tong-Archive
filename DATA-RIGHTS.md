# Data Rights and Attribution

The release makes the following catalogue and map materials publicly available with permission. The software license applies to the project's original code and software documentation. The source and reuse terms below apply separately to data and images.

| Public files | Source and use |
| --- | --- |
| `site/dist/catalogue.js` | Based on the 2024 edition of *致公堂档案细目*. Includes descriptive metadata from the Chee Kung Tong Archive, C. V. Starr East Asian Library, University of California, Berkeley, and a small number of explicitly identified image excerpts. Consult each linked [library record](https://guides.lib.berkeley.edu/aaads/digitalcollections) and the [UC Berkeley Library permissions policies](https://www.lib.berkeley.edu/about/permissions-policies) for item-specific reuse conditions. |
| `site/dist/gazetteer.js` | Catalogue-derived names and evidence associated with the released catalogue. The coordinate and external ID reference is [GeoNames](https://www.geonames.org/export/), used under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The [source record](data/gazetteers/geonames/source.json) identifies the snapshot. |
| `site/dist/assets/historical/world-1913.jpg` | *World.*, Rand McNally and Company and Schlitz Brewing Company, dated 1913 and published 1914, list no. 3490.001. David Rumsey Map Collection, David Rumsey Map Center, Stanford University Libraries. |
| `site/dist/assets/historical/sf-bay-1915.jpg` | *San Francisco and vicinity, California*, U.S. Geological Survey, published 1915, list no. 5742.000. David Rumsey Map Collection, David Rumsey Map Center, Stanford University Libraries. |

The [historical map manifest](data/historical_maps/manifest.json) records the item links, image checksums, dates and applicable rights references. See the collection's [copyright and permissions information](https://www.davidrumsey.com/about/copyright-and-permissions). The global base map uses [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) via world-atlas.

Permission to make this release publicly accessible does not grant downstream rights beyond the applicable source terms. The source workbook, source-image cache and internal working records are held separately.
